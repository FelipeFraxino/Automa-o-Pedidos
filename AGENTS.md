# Instruções do Work para Gestão de Pedidos – CBN Distribuidora

Ao receber uma mensagem que comece com `Execução pedidos Piraquara:`, leia e siga integralmente [docs/EXECUCAO-PEDIDOS-PIRAQUARA.md](docs/EXECUCAO-PEDIDOS-PIRAQUARA.md) antes de agir. O texto após os dois-pontos define o escopo daquela execução e prevalece sobre o padrão de data, quantidade, ordem e intervalo.

Use o conversor Piraquara deste projeto para gerar a planilha Reckitt/Reppos. Os vídeos operacionais fornecidos pelo usuário são a referência para a navegação no Reppos; consulte-os quando disponíveis e não invente passos ausentes. O pedido só conta como executado depois de conferir os itens no carrinho do cliente identificado pelo CNPJ. Nunca finalize, confirme, transmita ou fature sem autorização expressa e específica.

Este arquivo orienta o agente quando o repositório está no contexto do Work. O painel do aplicativo registra a solicitação e copia o comando; ele não executa os cliques sozinho.
